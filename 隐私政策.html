隐私政策

生效日期：2026 年 10 月 4 日

本政策适用于由 GitHub 用户 zss285456-sudo 配置、Google 授权页面名称为 rclone 的个人云盘工具，以及本应用介绍网站。

访问哪些数据

在使用者通过 Google OAuth 授权后，rclone 可以在授权范围内读取云盘文件名称、路径、标识符、大小、时间等元数据及存储配额；下载、上传或其他文件操作会处理相应文件内容。授予完整 Drive 权限时，客户端具有修改、移动或删除文件的能力；实际执行由使用者的命令及授权的自动化任务决定。

Google 处理账户登录与授权。本工具接收用于 API 访问的令牌，不接收 Google 账户密码。

如何使用这些数据

访问所得数据用于使用者请求的文件查看、传输、备份和管理，以及经使用者指示的文件分析。工具不将 Google 用户数据用于广告、出售数据或训练通用 AI 模型。

Google API 所得信息的使用及向其他应用转移遵守 Google API Services User Data Policy，包括其中的 Limited Use 要求。

智能体与第三方处理

使用者可以授权智能体调用本机 rclone。如果只执行文件传输，文件在本机与 Google Drive 之间传输；如果要求智能体读取、理解或分析文件，相应内容可能发送给使用者选择的 AI 服务提供方处理。此类处理还受该服务提供方的隐私政策与使用者账户设置约束。

使用者应根据文件内容与服务政策决定是否交由智能体处理。此应用不提供独立的云端文件存储服务，也不将云盘文件发布到本网站。

存储与保留

客户端凭据、授权令牌和连接设置保存在本机 rclone 配置文件中；文件内容保留在 Google Drive、使用者指定的本机目录及操作产生的缓存中。配置文件不应被视为已加密的安全保险库，需要通过设备与文件权限保护。

运行日志可能含文件路径、名称及错误信息，其位置和保留期限由使用者配置。使用者可删除本机下载副本、缓存及日志；删除连接配置前应先确保不再需要该连接。云盘文件的保留与回收站行为由具体操作及 Google Drive 设置决定。

撤销授权与删除数据

使用者可在 Google 账户第三方连接中移除本应用的访问权限，并删除本机对应连接配置。撤销授权不会自动删除已经下载的文件，已保存的本机副本需另行处理。

网站访问

本网站为 GitHub Pages 托管的静态页面，不添加分析脚本、广告或追踪 Cookie。GitHub 可能为服务运行及安全记录访问者 IP 等信息，详情见 GitHub 隐私声明。

联系与政策更新

政策更新会在本页面注明生效日期。可通过 GitHub Issues联系维护者；Issues 为公开反馈渠道，请勿提交授权令牌、客户端密钥、私人文件或其他敏感信息。
